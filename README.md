# Food Delivery Industry Analytics

## Overview

This project analyzes restaurant performance and customer behavior using:

- Zomato Bangalore Restaurants Dataset
- Online Food Delivery Dataset

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- GitHub

## Project Structure
food/
├── data/

## Project Highlights

- Data Cleaning
- Exploratory Data Analysis
- Restaurant Analytics
- Customer Behavior Analytics
- Business Insights Dashboard

## Analysis Performed
### Restaurant Analytics

- Rating Analysis
- Location Analysis
- Cuisine Analysis
- Cost Analysis
- Restaurant Popularity Analysis

### Customer Analytics

- Age Analysis
- Occupation Analysis
- Ordering Preferences
- Customer Satisfaction Factors
- Rating Influence Analysis


## Key Insights

- BTM and HSR are major restaurant hubs.
- Online ordering dominates restaurant operations.
- Customer ratings strongly influence food ordering decisions.
- Convenience and discounts drive food delivery adoption.
